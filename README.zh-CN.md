# changlong

面向长隆的 AI 智慧伴游方案，分三个阶段。

<sub>HTML · 参赛材料</sub>

---

## 思路

现在逛园区，靠的是游客自己加一块排队指示牌。这个方案想做一个覆盖全程的引导，分三段：

| 阶段 | 做什么 |
|---|---|
| 游前 | 了解偏好、生成路线、建立预期 |
| 游中 | 实时重规划——项目停运、排队时长、天气、孩子累了 |
| 游后 | 留下记录：照片、走过的路线、哪些安排有效 |

「游后」是大多数园区 App 会跳过的一环，也恰恰是让第二次游园更轻松的那一环。

## 仓库内容

参赛提交材料：三个阶段的方案文档与 HTML 演示，覆盖用户旅程和技术路径。

## 范围说明

这是一份方案，不是一个已交付的系统。涉及到具体行为的地方——比如项目停运时如何重规划——描述的是流程，并没有接真实的园区数据来实现。
